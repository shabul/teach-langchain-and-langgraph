# my-docs

Drop your own files here and the chat will answer questions about them.

**Supported formats:** `.md` `.txt` `.py` `.rst`

**Then run:**
```bash
./start.sh --reindex    # first time or after adding new files
./start.sh              # resume (no reindex needed)
```

Examples of what to put here:
- Meeting notes, personal wikis, project specs (`.md` / `.txt`)
- Your own Python scripts or a codebase you want to query
- Any text-based documentation
